# RESET REGEN 상세페이지 제작 기준

기준 화면은 `/regen` 재생치료 소개다. 기준 소스 커밋은 `952be5c`이며, 이 문서는 해당 화면의 실제 구현과 향후 상세페이지 적용 기준을 기록한다. 기존 인계 문서와 표현이 다르면 최신 사용자 지시와 현재 소스를 먼저 확인한다.

## 화면 구성과 브랜드

- 딥 네이비 `#0B1738`, 로고 원본 `#15B4A2`, 어두운 배경 위 민트 `#82DCCB`와 브론즈 `#D4B18B`를 사용한다. 밝은 배경에서는 진한 틸 `#087C70`과 브론즈 `#89633F`를 사용한다.
- 제목은 S-Core Dream, 본문은 Pretendard. 기본 섹션 제목은 `clamp(27px, 2.6vw, 36px)`와 굵기 500을 기준으로 한다. 요약 제목과 FAQ는 역할에 따라 별도 크기를 사용한다. 밝은 블루그레이와 딥 네이비를 번갈아 배치하고, 구분은 여백과 얇은 선으로 표현한다.
- 공통 본문 폭은 `.ro-wrap`의 `min(1120px, 88%)`. 640px 이하는 좌우 22px 여백과 좁은 화면 기준으로 전환한다. 본문 제목은 질문 또는 결론이 먼저 읽히게 구성한다.
- 공통 헤더 아래에 페이지 전용 히어로와 `RegenTabs`를 둔다. `/regen`에는 왼쪽 목차가 없다. 세부 페이지를 이 디자인으로 전환할 때 카테고리 탭은 공통 이동에 사용하고, 기존 섹션 앵커와 외부에서 연결되는 주소는 보존한다.
- 상세 헤더 높이는 기준 화면에서 PC 80px, 모바일 66px이고, 카테고리 바는 45px / 89px로 잡는다. 카테고리 바는 헤더 바로 아래에 고정한다. 레이어 순서는 헤더 60, 퀵메뉴 50, 카테고리 바 40이다.
- 헤더 드롭다운에는 중복 그룹 제목을 표시하지 않는다. 실제 경로를 기준으로 PC의 상위 메뉴와 펼친 목록의 현재 링크를 민트로 강조한다. `RegenTabs`와 헤더는 현재 위치에 `aria-current`를 제공한다.

## 세부 페이지 적용 순서

1. 각 페이지의 실제 진입점, 기존 메타데이터, 의료 정보, 섹션 ID·내부 링크를 확인한다. 리젠 주사는 이미 맞춤 화면을 쓰고, PRP·PRF, 무릎 SVF, 주사 성분 설명 원칙은 공통 기존 템플릿, 근거·연구는 별도 라우트다.
2. 헤더 → 카테고리 이름 H1과 짧은 안내를 담은 히어로 → 고정 카테고리 바 → 진료 내용을 바로 답하는 첫 본문을 공통 뼈대로 적용한다. 뒤의 비교 카드, 이미지와 평가 목록, 단계 흐름, FAQ는 각 주제에 필요한 패턴을 선택한다.
3. 환자가 원하는 답을 상단에 제시한다. PRP·PRF는 비교와 각각의 앵커, 무릎 SVF는 대상·과정·한계, 성분 설명은 설명과 동의, 연구 페이지는 근거 수준과 원문 연결을 우선한다. 기존의 안전 정보, 적용 조건, 참고 원문과 검토 상태를 보존한다.
4. SEO·GEO·AEO를 위해 페이지별 URL·제목·설명·PageData를 유지하고, H1과 본문 제목 계층 및 FAQ를 일반 HTML로 제공한다. 검토가 필요한 정보와 날짜는 페이지 하단에 현재 상태로 표시한다.
5. PC와 모바일 390px에서 제목 줄바꿈, 탭 고정, 퀵메뉴, 본문 앵커, 카드 잘림, 포커스와 스크롤 재진입을 확인한다. 빌드 후 요청 범위만 커밋·푸시한다. Cloudflare 배포 성공과 공개 화면 반영 여부는 GitHub 푸시와 구별해 기록한다.

기존 상세페이지에 위 기준을 적용하는 작업은 이 문서 저장과 별도로 진행한다.

## 상세페이지 이미지 캡션

사진 아래에 “모습을 표현한 예시입니다” 같은 일반 캡션을 추가하지 않는다. 대체 텍스트는 이미지의 내용을 간결히 설명하며, 생성 장면을 실제 진료 기록으로 표현하지 않는다.

## 사진과 본문 정렬

상세페이지 신규·수정 작업에서 사진과 옆 목록의 상단과 하단을 PC에서 맞춘다. 내용 길이로 열 높이를 정하고 사진은 해당 공간에 맞춘다. 핵심 피사체와 본문이 잘리지 않는지 확인한다. 모바일은 읽는 순서대로 세로 배치하고 사진 비율을 유지한다.
