# 여러 페이지를 한 번에 맡길 때 쓰는 지시문

이 프로젝트의 제작 범위는 사이트맵과 계획 JSON의 모든 페이지다. 병원 자료와 제작 키트의 섹션 카탈로그, 원본 소스, PC·모바일 기준 화면을 먼저 열어라.

1. 페이지별로 환자 질문, 섹션 순서, 가져올 원본 섹션과 실제 소스, 사용할 사진, 유지할 타이포·정렬·모션, 검증할 동작을 계획 JSON에 정리한다. 구체적인 섹션별 기준으로 기획하고 단순한 공통 목차만 반복하지 않는다.
2. 각 페이지를 기획→원고·사진→코드 조립→브라우저 확인 순서로 진행한다. 원본과 같아야 할 규격은 기존 코드와 CSS를 재사용하고, 페이지별로 그 진료를 이해시키는 장면이나 비교 방식, 과정 안내를 선택한다. 신규 환자·의료진 정보와 임상 주장에 리셋의 정보를 가져오지 않는다.
3. 완성 후 모든 페이지를 한 묶음으로 audit 한다. 자동 검사에 실패한 페이지는 원인을 수정하고 다시 실행한다. 하나의 결과 화면으로 다른 페이지의 구현을 추정하지 않는다.
4. 같은 너비에서 각 페이지의 기준 화면과 새 화면을 상단·중단·하단까지 비교한다. 브라우저에서 스크롤과 클릭을 다시 보고, 실제 비교 관찰을 각 PC·모바일 review 항목에 남긴다. 본문이 중간부터 계속 텍스트로 늘어지거나 사진과 본문이 어긋났다면 제작 단계로 돌아간다.
5. 준비 완료 검사 ready 를 실행한다. 통과한 페이지별 URL과 두 화면, 바뀐 내용, 검증한 동작을 한 번에 공유한다. 병원 확인이 필요한 사실은 모아 표시한다. 게시나 배포는 프로젝트에서 이미 승인된 경우에 수행한다.
